# Narcotics

RimWorld 1.6 mod by **Anarchist** that adds real-world-inspired narcotics using vanilla drug mechanics.

**Version:** 0.1.1

## Contents

| Drug | How you get it | Role |
|------|----------------|------|
| **Percocet** | Drug lab (neutroamine + herbal medicine) | Medical painkiller |
| **Xanax** | Drug lab (neutroamine + smokeleaf leaves) | Medical mood booster |
| **Weed** | Grow weed plant → harvest ready-to-smoke | Social high |
| **Cocaine** | Grow coca → refine leaves at drug lab | Hard stimulant |

All finished drugs are **buyable and sellable** with traders (Drugs category, `tradeability` All).

## Research

Requires **drug production**, then:

- Percocet production
- Xanax production
- Cocaine production

Weed needs no research to sow.

## Install

Copy or link this folder to:

`C:\Program Files (x86)\Steam\steamapps\common\Rimworld\RimWorld\Mods\Narcotics`

Enable **Narcotics** in the Mods menu.

## Compatibility

- RimWorld **1.6**
- Core only (no DLC required)
